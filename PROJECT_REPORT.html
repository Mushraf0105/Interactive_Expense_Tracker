1. Executive Summary

The Interactive Expense Tracker Web Application is a responsive, client-side personal finance management system engineered with zero external dependencies. The application is built entirely upon HTML5, CSS3, and Vanilla JavaScript (ES6+), utilizing the browser's LocalStorage API for full offline data persistence.

Users can perform full CRUD (Create, Read, Update, Delete) operations on their expenditures, filter transactions by custom or predefined categories, search by keywords, filter across customizable date ranges via a mobile-responsive calendar modal, sort records dynamically, and inspect live aggregated analytics including a visual category distribution bar.

4. Core Technical Modules

1. Form Subsystem & Combobox Category Entry

The Category selector was engineered as an interactive combobox input. Users can freely type custom categories or select standard defaults (🍔 Food, 🚗 Transport, 💡 Housing, 🎬 Entertainment, 💊 Healthcare, 🛍️ Shopping, 📦 Other). Any user-created category is automatically synchronized into the Filter Category dropdown.

2. Mobile-Responsive Custom Dropdowns (Smart Drop-Up)

To prevent native browser <select> popups from overflowing narrow cards on mobile, custom dropdowns were created. Dropdowns are strictly bounded to width: 100%. When space below is tight (<220px), the component automatically opens upward (.drop-up) with smooth touch-friendly scrolling.

3. Mobile-Responsive Calendar Modal & Quick Presets

Avoids native desktop Chromium calendar clipping by providing an accessible, centered modal dialog. Users navigate months with ease and pick dates with high-contrast feedback. Additionally, one-tap Quick Date Presets (Today, This Week, This Month, All Dates) make date filtering instant.

4. Mobile Card Transformation (≤640px)

Instead of cramped, overflowing tables on mobile viewports, the application transforms rows into individual receipt cards with clear attribute labels, styled badges, and prominent currency values.
